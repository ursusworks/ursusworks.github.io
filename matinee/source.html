LGPL libraries (FFmpeg and its libraries)

FFmpeg, libiconv, liblzma (XZ Utils) are used under the GNU Lesser General Public License, as unmodified libraries in separate DLLs that Matinee links to dynamically. You may modify them and use your modified versions with Matinee, and reverse-engineer Matinee as far as needed to debug such modifications.

The complete corresponding source code is available at the links above. Unmodified FFmpeg libraries (avcodec, avformat, avutil, avfilter, avdevice, swresample, swscale), built from FFmpeg commit 38b88335f99e with the build scripts of FFmpegInteropX (https://github.com/ffmpeginteropx/FFmpegInteropX/tree/841fc8e79346a235906f1dbd45be53034b2e2f52/Build) and shipped as separate DLLs that Matinee links to dynamically.
