Matinee

Matinee is an Emby client for Xbox Series X|S. It plays the movies and shows on your own Emby server, and can show what Sonarr and Radarr have coming up.

Support

Email ursusworks@outlook.com. Please include your Matinee version (Settings → About), your Emby server version, and what you were doing when the problem happened.

Common questions

Do I need an Emby server? Yes. Matinee is a client: it doesn't come with any content, and it doesn't work with other media servers.

Matinee can't find my server. Enter its address on the first screen, e.g. 192.168.1.20:8096. The console and the server must be on the same network, or the server must be reachable from it.

Sonarr / Radarr won't connect. Enter the address in Settings → Sonarr & Radarr. Matinee reads the API key itself if Sonarr/Radarr allow local access without a login ("Disabled for local addresses"); otherwise paste the key from their Settings → General.

A video won't play or keeps buffering. Lower Settings → Playback → Maximum streaming quality, or check that your Emby server can transcode.
